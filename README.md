# TermLauncher
<sub>Note: <ins>This project is being made for fun! Please no hate!</ins></sub>

### Features
- Home screen
- App drawer
- Wallpaper (animated rain by default, supports gif)
- Settings (`[ cfg ]`)

### Requirements
- Android 9 (API 28) or newer

### Limitations

An app can't restyle system screens (Settings, other apps, the keyboard) without root, so TermLauncher only replaces the home screen and app drawer.

## Guides
### Installation
First go to the releases and download the latest release by clicking on a file named `TermLauncher.apk`, after downloading click on it and press install. While installing it can say "Harmful app blocked".

![image alt](https://github.com/MewsterCat/TermLauncher/blob/d55919b75ed555e977ab62a575722ff960a850ef/images/TermLauncher-Installation-Warning-Pic.jpg)

Above a button "Got it" press a text that says "More details ↓".

![image alt](https://github.com/MewsterCat/TermLauncher/blob/d55919b75ed555e977ab62a575722ff960a850ef/images/TermLauncher-Installation-Warning-Pic1.jpg)

After you clicked it click a text that says "Install anyway".

### Updating
Note: <ins>You don't have to uninstall the already installed one!</ins>

To update the app you have to download the latest release, when downloaded click on it, it will ask you to update. While updating it can say "Harmful app blocked", above a button "Got it" press a text that says "More details ↓". After you clicked it click a text that says "Install anyway".
